# 45_student_crud_system

A concise CRUD application for managing student records with validation.

Usage examples:
- Create: python student_crud.py create "Bob" 16 "10th"
- Read all: python student_crud.py read
- Update: python student_crud.py update 1 --age 17
- Delete: python student_crud.py delete 1

Improvement suggestion:
- Add pagination and search by name or grade.
