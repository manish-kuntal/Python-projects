# 34_screenshot_tool

Take a screenshot and save it with a timestamped filename.

Requirements:
- Pillow is recommended: pip install Pillow
- On some Linux systems, pyscreenshot may work better: pip install pyscreenshot

Usage:
- python screenshot.py  (saves to ~/Pictures by default)
- python screenshot.py /tmp/screenshots

Possible improvement:
- Add area selection and a small GUI using Tkinter.
