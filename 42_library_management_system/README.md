# 42_library_management_system

An object-oriented library system with Book and Member records, and loan management.

How to use:
- Run library.py to see current data (demo mode).
- Use the Library class in scripts to add books/members and call borrow/return.

Python concepts:
- Classes, JSON persistence, basic OOP methods.

Improvement suggestion:
- Add a CLI wrapper and due-date tracking with overdue notifications.
