# 12_student_record_manager

Simple JSON-backed student record manager with basic CRUD operations.

Usage examples:
- Add: python manager.py add "Alice" 14 "8th"
- List: python manager.py list
- Find: python manager.py find 1
- Update: python manager.py update 1 --name "Alicia" --age 15
- Delete: python manager.py delete 1
