# 15_notes_manager

Manage simple notes with tags stored in `notes.json`.

Usage examples:
- Add: python notes.py add "Shopping" "Buy milk and eggs" --tags groceries,home
- List: python notes.py list
- Find: python notes.py find milk
- Edit: python notes.py edit 1 --content "Buy milk, eggs, and bread"
- Delete: python notes.py delete 1
